## Overview

**QRCoder** is a small Python command-line tool that turns a link (usually a URL) into a scannable PNG QR Code. On top of plain generation, it can insert a **centered logo** to give the code a visual identity for your brand.

Codes are generated with error-correction level **H** (the highest available), so they stay reliable to scan even with a logo overlaid in the center.

## Features

- Encode any link (up to 2,953 characters) into a PNG QR Code.
- Optionally embed a **centered logo**, auto-resized to at most a quarter of the code width.
- Highest error-correction level (**H**) for reliable scanning.
- Graceful fallback: an invalid or missing logo never breaks generation.
- Isolated, reproducible environment powered by [uv](https://docs.astral.sh/uv/).

## Prerequisites

- **Python 3.11+**
- **[uv](https://docs.astral.sh/uv/)** — manages dependencies and runs the tool in an isolated environment. See the [official installation guide](https://docs.astral.sh/uv/getting-started/installation/).

## Installation

QRCoder uses [uv](https://docs.astral.sh/uv/) to manage its dependencies in an isolated virtual environment, so nothing is installed into your global Python.

```bash
git clone <REPOSITORY_URL>
cd qrcoder
uv sync
```

`uv sync` creates a local `.venv`, installs the runtime dependencies (`qrcode`, `Pillow`), and registers the `qrcoder` command inside that environment.

## Usage

Run the tool through `uv run`, which activates the isolated environment automatically.

### Arguments

| Argument          | Required | Description                                          |
| ----------------- | :------: | ---------------------------------------------------- |
| `link`            |    Yes   | The link (URL) to encode in the QR Code.             |
| `--logo` / `-l`   |    No    | Path to a logo image to insert in the center.        |
| `--output` / `-o` |    No    | Custom path for the generated PNG file.              |

### Generate a simple QR Code

```bash
uv run qrcoder "https://example.com"
```

This produces a scannable QR Code like the one shown at the top of this page.

### Generate a QR Code with a logo

```bash
uv run qrcoder "https://example.com" --logo logo.png
```

## Output location

When you do **not** pass `--output`/`-o`, the QR Code is saved inside the **`output/`** directory at the project root. This directory is created automatically on the first run and is ignored by Git, so generated files never get committed.

| Scenario      | Default file                     |
| ------------- | -------------------------------- |
| Without logo  | `output/qrcode_simple.png`       |
| With logo     | `output/qrcode_with_logo.png`    |

To save somewhere else, pass an explicit path:

```bash
uv run qrcoder "https://example.com" --output my-code.png
```

## Logo fallback behavior

If the path given to `--logo`/`-l` **does not point to an existing, valid image**, QRCoder prints a warning and **still generates the QR Code, just without the logo**. Generation is never interrupted by a bad logo path.
